Google Business Profile
Set up the free listing so customers find Mimshak Pak on Google Maps and Search

Setup checklist

  • Create the listing
    Go to business.google.com → Add your business → Search "Mimshak Pak Investments"
  • Choose the right category
    Primary: Packaging Company — add secondary: Printing Company and Manufacturer
  • Add the address
    No 3 Austin Ugbo Onyeje Avenue, Orjimiyana, Asaba, Delta State
  • Add phone numbers
    Primary: 0803 707 9976 — Secondary: 0810 306 4976
  • Add website URL
    https://www.mimshakpak.com
  • Set business hours
    Monday – Saturday: 8:00 AM – 6:00 PM, Sunday: Closed
  • Upload facility photos
    Add 8–12 photos: factory floor, machines, finished products, team. Real photos rank higher.
  • Verify the listing
    Google sends a postcard with a verification code to the business address. Enter it when it arrives (usually 5–14 days).
  • Add services
    List: Carton Printing, Custom Carton Packaging, Nylon Print Packaging, Industrial Packaging, Branded Packaging
  • Ask first customers for reviews
    After verification, request Google reviews from existing clients — even 3–5 reviews significantly boosts local search ranking.
How to Update the Website
Step-by-step guide for making common changes — no coding required for most tasks

Add or edit a blog post

1

Go to the GitHub repository

Open github.com/zaddyjohn-cyber/mimshak-pak-website and sign in as zaddyjohn-cyber.

2

Find the blog post file

Blog posts are files like blog-carton-packaging-asaba.html in the root folder. Click the file name to open it, then click the pencil ✏️ icon to edit.

3

Edit the text and save

Change the text between the HTML tags. When done, scroll down, write a short commit message (e.g. "Update blog post"), and click Commit changes.

4

Site updates in ~60 seconds

GitHub Pages rebuilds automatically. Refresh the live site after about a minute to see the changes.

Change a phone number or email

1

Open main.js

Go to Edit main.js on GitHub — all contact details are at the top in the CONTACT block.

2

Find the right field

phoneDisplay is the number shown on the page. phoneTel is what the phone dials — it must start with +234 and have no spaces. Update both together.

3

Commit and it's live

Scroll down → Commit changes → done. The new contact info will appear on every page of the site.

Add a new photo

1

Upload to the images folder

In the GitHub repo, open the assets/img/ folder → click Add file → Upload files → drag in the new JPEG photo.

2

Reference it in a page

Open the HTML page you want to update. Find the <img src="assets/img/…"> tag and change the filename to your new photo's filename.

Need help?

For anything beyond these tasks — new pages, layout changes, SEO updates — contact the developer. Keep a note of what you want changed and they can implement it quickly.
