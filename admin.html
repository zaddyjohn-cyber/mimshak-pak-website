How to Update the Website
Common tasks and how to do them

Update contact details

Use the Edit Contact tab — load the current values, make your changes, and click Save to website. The site updates automatically in about 60 seconds. No GitHub account needed.

Add or edit a blog post

1

Open the file on GitHub

Go to the Pages tab and click Edit ↗ next to the blog post you want to change. You'll need to sign in to GitHub.

2

Edit the text

Change the text between the HTML tags. Don't touch anything that starts with < unless you know what it is.

3

Commit and it's live

Scroll down → write a short note (e.g. "Update blog post") → click Commit changes. Site refreshes in ~60 seconds.

Add a new photo

1

Upload to the images folder

In the GitHub repo, open assets/img/ → click Add file → Upload files → drag in the JPEG photo → commit.

2

Reference it in a page

Open the page you want to update via the Pages tab. Find <img src="assets/img/…"> and change the filename to your new photo's name.

Settings
One-time setup to allow direct editing from this admin panel

GitHub Access Token

This token lets the admin panel save changes directly to the website without needing a GitHub account. It only takes 3 minutes to set up and you only do it once on each device.

How to get your token (do this as the website owner):

  1. Go to github.com → Settings → Developer settings → Fine-grained tokens
  2. Click Generate new token
  3. Name it Mimshak Pak Admin — set expiration to 1 year
  4. Under Repository access, choose Only select repositories → pick mimshak-pak-website
  5. Under Permissions → Repository permissions, find Contents → set to Read and Write
  6. Click Generate token — copy the token (starts with github_pat_)
  7. Paste it below and click Save token

The token is saved only on this device (browser storage). It is never sent anywhere except directly to GitHub's secure API.
